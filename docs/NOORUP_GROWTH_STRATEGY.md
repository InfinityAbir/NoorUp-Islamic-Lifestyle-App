# NOORUP Growth Strategy (ethical, organic-first)

> **[PDF]** = from the ReelBlink guide or Store Checklist. **[Analysis]** = my own recommendation for NoorUp — test and adapt.
> The ReelBlink "100+ downloads" report is one developer's experience, not a prediction. No download number is promised here.

## 1. Principles from the PDFs

- **ASO first [PDF]**: a clear listing helps discovery and conversion. ReelBlink points to its own ASO/referral/free-site guides via Drive links — those linked guides were not inspected here; evaluate them separately before following.
- **Reels had the biggest impact [PDF]**: Trial Reels on Instagram, cross-posted to Facebook / Threads / YouTube, experimenting with regions beyond India only. Treat as directional, not guaranteed.
- **Free launch/promotion sites [PDF]**: submit to free app-launch directories (the guide claims 30+). Vet each for relevance, spam risk, and effort; a few quality listings beat mass submission.
- **PDF-as-funnel [PDF]**: ReelBlink embedded its Play link at the top of every free PDF shared via Reel → Comment → PDF → install. Adaptable to NoorUp only with genuinely useful Islamic resources (see §4).
- **One message per visual, honest representation [PDF]**: applies equally to Reels/Shorts covers and listing screenshots — show only what v1.2.0 does.

## 2. Positioning (why NoorUp can spread)

Bengali-first companion for Bangladesh/West Bengal that works offline with no ads SDK: prayer times with method/juristic options and Makruh/Sehri/Iftar display (calculated — verify with masjid), Quran index + bundled offline text (translation source pending disclosure), 18 Duas and Hadith library in Bangla with references, Zakat in Vori/Taka, Tasbih, Hijri events, Qibla guidance (field accuracy unverified), widget + alerts, consistency/Qada tracking. Audience: practicing Bengali speakers, elders/new learners, students/professionals, families, travelers. Language: lead with বাংলা, offer English twin **[Analysis]**.

## 3. Short-form video plan (Reels / Facebook Reels / YouTube Shorts)

Cadence **[Analysis]**: 2–3 posts/week for 6 weeks, then keep what retains. One benefit per video (checklist rule). First 2 seconds = felt situation; next 15–25s = real screen recording; end = calm CTA.

Starter backlog (all filmable from the real app today):

1. "Missed Asr again?" → orbit countdown + per-prayer alert toggle (no "never miss" promise).
2. Sehri/Iftar bar + Makruh window explained in 20s (say "shown for caution", not "guaranteed").
3. Dua in 10s: one of the 18 Duas, Arabic → Bangla meaning → copy/share.
4. Zakat in Vori: enter gold → 2.5% result (show Nisab basis).
5. Qada ledger: missed day → made-up tracking.
6. Offline test: airplane-mode built-in answer + Quran open (say "built-in answers", not LLM).
7. Widget pin to home screen in 15s.
8. Hijri event countdown + Tasbih counter.

Production rules **[Analysis]**: real screen recordings only (no mock UI that over-promises); large Bangla captions readable on phones; get consent for any face/voice; disclose test/closed status while in testing; reuse the content-plan scripts in `NOORUP_PROMOTIONAL_CONTENT_PLAN.md`. Cross-post natively to IG Reels, FB Reels, YouTube Shorts (plus Threads repost) — do not spam the same clip hourly.

## 4. Communities + ethical organic promotion

Do: answer real questions in Bengali Islamic study, student, expatriate, and local mosque/community groups; share one useful Dua/prayer-time explanation with a reference, link only when asked or where rules allow; credit sources; respect Ramadan/adab; never DM-spam **[Analysis]**.

Do not: buy installs/reviews, incentivized ratings, review-swaps, misleading "No.1 / guaranteed reward" claims, keyword-stuffed comments, or mass cross-posting that violates group rules. These risk Play policy action and destroy trust.

Free platforms: evaluate a shortlist first (e.g. Product Hunt, Indie Hackers/Reddit relevant subs, AlternativeTo/Slant-style directories, Bengali tech blogs, mosque notice boards/WhatsApp with permission). Check each site's current submission rules before posting — requirements change **[Analysis]**.

PDF funnel adaptation **[Analysis]**: only if you already produce genuinely useful free PDFs (e.g. Ramadan Sehri/Iftar explainer). Put the Play link + QR on page 1 and last page with "Free companion app (works offline, no ads SDK)". Funnel: Reel → Comment "PDF" → DM/share PDF → try app. Never gate a religious text behind an install.

## 5. Calls to action (closed test vs public)

- **During closed testing**: "Join the closed test — link in bio. Report prayer-time errors for your city." Do not ask for public ratings yet; collect city + device + screenshot of any wrong time **[Analysis]**.
- **After public release**: "Install free • Works offline • No ads SDK. If it helps your daily practice, an honest Play review helps others find it." One CTA per video/description. Never condition features or content on rating. Always add: "Times are calculated — verify with your masjid."

## 6. Referral functionality — optional, deferred

Status: no referral/invite/rewards code exists (only Dua/Hadith system-share). The ReelBlink guide suggests adding one, but for offline-first NoorUp with no accounts/backend it adds fraud, support, and policy risk for unclear gain **[Analysis]**.

Recommendation: ship without referrals. If retention (D7/D30, streak continuation) later justifies it, add the smallest honest version: system-share sheet with Play link + optional `referrer` UTM for measurement only — no points, no gated features, no incentivized ratings. Requires approval + Play policy check before building.

## 7. Metrics (measure, don't guess)

- Listing: store-listing visitors → installs (Console conversion), per-screenshot swipe retention if available, search-term impressions.
- Installs: total + by channel (UTM/`referrer` per video + per PDF version), closed-test opt-ins vs activations.
- Engagement: prayer check-in completion, Tasbih uses, Dua/Hadith shares, widget pins, alert opt-in rate, assistant queries.
- Retention/quality: D1/D7/D30, streak continuation, Qada made-up rate, crash/ANR rate, exact-alarm delivery, uninstall + review sentiment (accuracy complaints first).
- Cadence **[Analysis]**: weekly review during closed test; keep/double-down on the top-2 video themes, kill the bottom-2. No paid spend until organic retention is proven.
